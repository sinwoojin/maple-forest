# v4 콘텐츠 목록과 확장 지점

현재 코드에 있는 콘텐츠의 요약입니다. 수치는 장비·유물·빌드가 함께 적용되기 전 기본 효과입니다. 공격·방어 보너스는 별도 표시가 없으면 해당 원정 안에서만 유지됩니다.

| ---------------- | ----------- | -------------------------------------------------------------------- |
| 전사 `counter`   | 반격 수호자 | 기술 후 1.4초 방어, 막은 공격에 주변 반격                            |

## 이벤트 12개

공통 등장 규칙: 갈림길의 **이벤트 경로**를 골랐을 때 등장합니다. 보스가 아닌 다음 단계의 보급 경로는 이벤트→상점→휴식 순환이며, 실제 이벤트는 원정 시드 기반으로 **이번 원정에서 아직 만나지 않은 항목을 우선** 선택합니다. 확률 추첨값과 유물 후보는 선택 전에 저장됩니다. 새로고침으로 다시 추첨하지 않습니다.

모든 이벤트에는 비용·보상 없는 **조용히 지나간다**가 있습니다. 직업 조건 불충족이나 자원 부족 선택은 비활성화됩니다. HP 비율은 최대 HP 기준이며 올림 계산, 이벤트 HP 손실은 최소 1HP를 남깁니다. 회복은 최대 HP를 넘지 않습니다. 미보유 유물이 모두 소진되면 유물 보상은 50골드로 바뀝니다.

| ID / 이벤트              | 선택: 조건·비용 → 효과                                                      |
| ------------------------ | --------------------------------------------------------------------------- |
| `spring` 빛나는 샘       | 마시기: 40골드 → HP·MP 완전 회복. 담기: 무료 → 물약 +1                      |
| `bridge` 끊어진 다리     | 뛰기: 무료 → 60%로 90골드, 실패 HP −20%. 수리: 재료 2 → 70골드              |
| `smith` 떠돌이 대장장이  | 벼리기: 재료 3 → 공격 +7. 돕기: 무료 → 재료 +2                              |
| `shrine` 잎새의 제단     | 생명 바치기: HP −25% → 방어 +3. 금 바치기: 50골드 → 미보유 유물             |
| `fox` 길 잃은 여우       | 먹이: 물약 1 → 100골드. 따라가기: 무료 → 50%로 유물, 실패 HP −15%           |
| `archive` 고대의 서고    | 읽기: MP 20 → 공격 +6. 필사: 무료 → 35골드                                  |
| `garden` 달빛 약초밭     | 수확: HP −15% → 물약 +4. 향기: 무료 → HP +25%                               |
| `gambler` 도토리 주사위  | 내기: 40골드 → 50%로 120골드, 실패 보상 없음. 짐 들기: 무료 → 20골드        |
| `ghost` 기억의 유령      | 겨루기: 전사만, 자원 비용 없음 → 공격 +8. 듣기: 무료 → MP 완전 회복·재료 +1 |
| `nest` 바람새의 둥지     | 쏘기: 궁수만, 자원 비용 없음 → 미보유 유물. 오르기: HP −20% → 75골드        |
| `crystal` 노래하는 수정  | 공명: 마법사만, 자원 비용 없음 → 공격 +8·MP 완전 회복. 캐기: 무료 → 재료 +4 |
| `caravan` 멈춰 선 대상단 | 부적: 물약 2 → 방어 +4. 광석 판매: 재료 2 → 90골드. 식사: 무료 → HP +20%    |

정의는 `event-data.js`, 등장·조건 검사·효과·선택 저장은 `events.js`입니다. 항목 수를 바꿀 때 `prepareRunEvent`의 현재 상수 `12`도 실제 카탈로그 길이에 맞춰 변경하고, 새 효과는 적용기와 저장 검증을 함께 확장해야 합니다.

## 적 역할 8개와 보스 4종

| 역할 ID    | 실제 차이                                    |
| ---------- | -------------------------------------------- |
| `charger`  | 접근 후 경고를 띄우고 빠르게 돌진            |
| `ranged`   | 근접 시 후퇴, 경고 뒤 투사체                 |
| `shield`   | 플레이어 방향으로 방어, 경고 뒤 방패 타격    |
| `leaper`   | 목표 위치에 경고 후 도약                     |
| `bomber`   | 접근 후 넓은 지연 폭발                       |
| `summoner` | 살아 있는 적 수 제한 안에서 증원 소환        |
| `healer`   | 가까운 가장 다친 동료 HP +18, 주변 파동 공격 |
| `stealth`  | 은신 접근 후 기습 경고                       |

정예 경로는 보스 우선 규칙을 제외한 4의 배수 단계에서 제시됩니다. 우선 처치 표식의 치유 적이 살아 있으면 동료가 초당 3HP 회복하고, 정예 완료 보너스는 90골드·재료 3개입니다. HP를 단순히 늘리는 별도 정예 배수는 없습니다.

| 보스 ID / 단계  | 순환 패턴                                  |
| --------------- | ------------------------------------------ |
| `forest` / 10   | 뿌리 경고 → 돌진 → 돌진형 증원             |
| `cavern` / 20   | 순차 수정 경고 → 지면 충격파 → 폭탄형 증원 |
| `frost` / 30    | 둔화 얼음 → 연속 눈보라 → 도약             |
| `twilight` / 40 | 양옆 균열 → 양쪽 투사체 → 넓은 지면 일식   |

보스는 남은 HP 65%·30%를 경계로 3단계 행동을 사용하며 단계에 따라 경고 수와 재사용 시간이 달라집니다. 역할 로직은 `enemy-ai.js`, 보스 순환은 `boss-ai.js`, 배치·정예·목표는 `encounters.js`에 있습니다.

## 장비 특성

기본 장비 3종 무기와 기본 망토에는 추가 특성이 없습니다. 아래 특성은 장착해야 적용됩니다. 무기 공격력은 등급별 0/9/18/30, 방어구 방어력은 0/3/7입니다.

| 장비 ID     | 추가 특성                                    |
| ----------- | -------------------------------------------- |
| `warrior-1` | 검격 범위 +30                                |
| `warrior-2` | 기술 후 방어 0.5초, 반격 빌드 방어 시간 연장 |
| `warrior-3` | 기술 시 전방 70 이동·0.2초 무적, 추가 MP 5   |
| `archer-1`  | 화살 명중 둔화 +0.8초, 최대 4초              |
| `archer-2`  | 화살 관통 +1                                 |
| `archer-3`  | 화살 명중 MP +1, 기술 재사용 시간 +20%       |
| `mage-1`    | 일반 공격 명중 MP +1                         |
| `mage-2`    | 기술 명중 빙결 +0.4초                        |
| `mage-3`    | 기술에 3초 불길, 추가 MP 5                   |

장비 정의·비교·분해는 `systems.js`, 특성의 실제 소비는 `builds.js`·`combat.js`에 있습니다. 분해는 판매가/15의 내림값(최소 1)만큼 재료를 주며, 장착 중이거나 기본 장비인 항목은 보호합니다. 원정 장비 보상은 단계 등급에 맞는 미보유 무기·방어구를 우선하고, 후보가 없으면 재료 4개를 제시합니다.

## 수정할 파일과 확인 사항

| 변경                            | 파일                                                        |
| ------------------------------- | ----------------------------------------------------------- |
| 직업·장비/특성                  | `systems.js`, `builds.js`, `combat.js`                      |
| 유물 목록·효과                  | `relics.js`, 효과를 소비하는 전투 코드                      |
| 이벤트 내용·조건·등장           | `event-data.js`, `events.js`                                |
| 갈림길·상점·휴식                | `route-content.js`                                          |
| 적 역할·보스·목표/정예          | `enemy-ai.js`, `boss-ai.js`, `encounters.js`                |
| 원정 진행·보상·정상 능력치 복귀 | `stages.js`                                                 |
| 저장 형식·허용 ID/종류          | `run-validation.js`, `persistence.js`, `meta.js`            |
| 메뉴·설명·표현                  | `stage-ui.js`, `menus.js`, `archive-ui.js`, 해당 `*-art.js` |

새 ID나 선택 종류는 카탈로그 추가만으로 끝나지 않습니다. 저장 검증의 허용 목록, 실제 효과, 메뉴 표시, 결정적 테스트를 함께 갱신하세요. 새 스크립트는 `index.html` 로드 순서에 넣으면 정적 패키징과 로컬 서버가 이를 참조합니다. 변경 후 `npm test`, `npm run build`, 관련 브라우저 입력 검사를 실행합니다.
